# CogniBase

AI‑Powered Knowledge‑Base & Chat for SMBs

## Overview
CogniBase provides a unified document hub with AI‑driven tagging, semantic search, and a conversational chat assistant. Teams can upload PDFs, Word docs, Markdown, and images, then instantly ask natural‑language questions that retrieve relevant information with citations.

## Features
- Document upload & versioning
- Automatic LLM tagging & 2‑sentence summaries
- Vector‑based semantic search
- Chat assistant with source citations
- Role‑based access control & audit logs
- Slack & Microsoft Teams integrations
- Analytics dashboard (search trends, knowledge gaps)

## Quick Start
```bash
# Clone the repo
git clone https://github.com/your‑org/cognibase.git
cd cognibase

# Install dependencies
npm install

# Run locally
npm run dev
```
